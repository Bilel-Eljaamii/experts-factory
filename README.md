# 🧠 Gemma Expert Factory

An industrial-grade pipeline for transforming **Gemma 2 9B/8B** into domain-specific experts (Cybersecurity, Agriculture, etc.) using **Unsloth** and **QLoRA**. This project is optimized for high-speed training and low VRAM consumption (capable of running on a single 16GB T4 GPU).

## 🚀 Overview

The **Expert Factory** is designed to scale. Instead of managing a single fine-tuned model, this repository provides the infrastructure to ingest raw PDFs, synthesize expert-level instructions, and train modular adapters for any domain.

### Key Features

- **Lightning Fast:** Powered by [Unsloth](https://github.com/unslothai/unsloth), making fine-tuning 2x faster with 70% less memory.
- **Modern Python Tooling:** Managed by [uv](https://github.com/astral-sh/uv) for instant dependency resolution and reproducible environments.
- **Data-Centric Pipeline:** Structured workflow from raw PDF extraction to synthetic Q&A generation.
- **Multi-Expert Architecture:** Config-driven training for separate domains (Cyber, Agri, Finance) within one codebase.

## 🛠️ Setup & Installation

### 1. Install `uv`

If you don't have the `uv` package manager:

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```

### 2. Initialize Environment

From the project root, sync all dependencies (Torch, Unsloth, etc.):

```bash
uv sync
```

## 🏎️ The Expert Pipeline

### Step 1: Raw Knowledge Extraction

Place your PDFs in `data/raw/<domain>/`. Convert them to clean, layout-aware Markdown using `marker-pdf`:

```bash
uv run marker_single data/raw/agriculture/crop_science.pdf data/processed/agriculture/
```

### Step 2: Synthetic Data Generation

Raw text isn't enough for a chat model. Use a "Teacher" model (like GPT-4 or Llama 3 70B) to transform clean text into Instruction/Response pairs:

- **Format:** Alpaca or ShareGPT JSONL.
- **Goal:** Create 500-2000 high-quality Q&A pairs in `data/synthetic/<domain>/`.

### Step 3: Domain-Specific Fine-Tuning

Configure your training parameters in `configs/<domain>_config.yaml`. Then, launch the training:

```bash
uv run scripts/training/train_expert.py configs/agriculture_config.yaml
```

### Step 4: Export to GGUF

Once training is complete, export your expert for local use in Ollama or LM Studio:

```python
# Part of the training script
model.save_pretrained_gguf("models/final_gguf/agri_expert", tokenizer, quantization_method = "q4_k_m")
```

## ⚙️ Configuration

Each expert is governed by a YAML config in the `configs/` folder. Example:

```yaml
# configs/cybersecurity_config.yaml
project_name: "cyber-expert-v1"
base_model: "unsloth/gemma-2-9b-it-bnb-4bit"
max_seq_length: 2048
learning_rate: 0.0002
lora_rank: 32           # Higher rank for technical domains
target_modules: ["q_proj", "k_proj", "v_proj", "o_proj"]
```

## 🧪 Evaluation

To ensure your expert is actually an expert:

1. **Persona Check:** Use `scripts/eval/chat.py` to prompt the model with domain-specific edge cases.
2. **Benchmark:** Use the `AgriBench` or `CyberBench` datasets (if available) to score accuracy against base models.
